## 💻 Run Locally

### Prerequisites

-   Node.js compatible with the project's Next.js version
-   Git
-   npm (or Bun, if the project includes the relevant lockfile)

### Setup

``` bash
git clone https://github.com/Muneeb-Tahir/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Open <http://localhost:3000> in your browser.

### Production build

``` bash
npm run build
npm run start
```
